# QGIS-wildfire-portfolio
Los Angeles County Wildfire Hazard Analysis- QGIS Project.
Developed a comprehensive wildfire risk assessment map for Los Angeles County using QGIS 3.x.

Key Tasks:
• Imported and processed official CAL FIRE Fire Hazard Severity Zone (FHSZ) data
• Integrated OpenStreetMap roads, ESRI satellite imagery, and LA County boundary
• Performed spatial analysis of Very High and High hazard zones in the Wildland-Urban Interface
• Created a professional cartographic layout with legend, scale bar, north arrow, and analysis summary

Technical Skills Demonstrated:
- Layer styling and classification
- Symbology and transparency management
- Print layout design and high-resolution export
- Working with real U.S. government geospatial datasets

This project showcases my ability to analyze and visualize environmental risk data — directly relevant to GIS, disaster management, and AI training tasks.
